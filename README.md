# DataQA — сайт на английском (инструкция на русском)

Статический сайт без сборки: HTML, CSS, JS и необязательный `send.php` для отправки заявок через ваш сервер.

## Перед публикацией — обязательно

1. **Домен.** Замените `https://data-verification.com` на свой домен во всех файлах:
   `index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, `.well-known/security.txt`.
   Пример: `grep -rl example.com . | xargs sed -i 's#https://data-verification.com#https://yourdomain.com#g'`
2. **Контакты.** Email и Telegram — в `config.js`, `index.html` (JSON-LD и подвал), `llms.txt`, `security.txt`.
3. **Telegram.** В `send.php` вставьте токен бота в `TELEGRAM_BOT`.
   Группа «Заявки по данным» уже указана: `TELEGRAM_CHAT = '-1003852428895'`. Почта выключена (`EMAIL_TO = ''`).
4. **Шаблоны, которые нужно заполнить правдой:**
   - блок «Who's behind DataQA» в `index.html`: имя, опыт, ссылка на LinkedIn, фото вместо инициалов;
   - срок удаления данных «30 days» (блок Data security и privacy.html) — поставьте срок, который реально соблюдаете;
   - «We reply within one business day» под формой — оставьте, только если готовы отвечать так быстро;
   - «NDA and DPA» — оставьте, если действительно готовы их подписывать (шаблон DPA стоит подготовить заранее);
   - `privacy.html` — все места в [квадратных скобках], и уберите жёлтую плашку «Template».
5. Загрузите все файлы в корень сайта, включая папку `.well-known`. Отправьте тестовую заявку и проверьте, что она пришла в группу.

| Файл | Что это |
| --- | --- |
| `index.html` | Страница. Места для кода аналитики — комментарии `TRACKING` |

| `config.js` | Куда уходят заявки, контакты, цены |
| `set-domain.sh` | Смена домена во всех файлах одной командой |

| `llms.txt` | Краткое описание услуг и цен для AI-ассистентов |

## Что сделано для поиска и AI-систем

- **Структурированные данные (JSON-LD)** в `<head>`: услуга, цены по каждому тарифу и FAQ. По ним Google и AI-ассистенты понимают, что вы продаёте и сколько это стоит.
- **Цены и ответы на вопросы — обычным текстом в HTML.** Они не зависят от JavaScript, поэтому боты видят всё.
- **Блок-определение «What is analytics data reconciliation?»** — короткий абзац, который удобно цитировать.
- **`llms.txt`** — та же информация в формате для языковых моделей.
- **`robots.txt`** явно пускает AI-ботов; `send.php` закрыт от индексации.
- **Canonical, Open Graph и семантическая разметка** (заголовки, `<dl>`, `<details>`).

## Куда уходят заявки (config.js → LEADS.mode)

По умолчанию стоит `php`: `send.php` шлёт заявку в Telegram-группу и сохраняет копию в CSV уровнем выше папки сайта.
Другие режимы — `formspree`, `web3forms`, `hubspot`, `bitrix24`, `webhook`, `mailto` — описаны в комментариях `config.js`.

Вместе с заявкой приходят: выбранная услуга и расчёт, UTM-метки, gclid / fbclid / yclid, реферер, страница входа и `lead_id`.

## Аналитика

Код GTM, GA4 и пикселей вставляйте в места `TRACKING` в `index.html`. Сайт сам отправляет в `dataLayer`:

- `service_select` — выбрана услуга;
- `calculator_change` — изменён расчёт;
- `form_start` — начато заполнение заявки;
- `generate_lead` — заявка отправлена, параметры `lead_id`, `service`, `value`, `currency`.
